# ⏱️ StopWatch Project

A simple stopwatch built using HTML, CSS, and JavaScript.

## 🚀 Features
- Start / Stop button
- Reset button
- Clean UI

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## 📌 How to use
1. Click Start to begin timer
2. Click Stop to pause
3. Click Reset to reset time
